One line about office life: a five-star review, a 0% raise, and the word
"priceless" doing double duty. `main.py` writes the joke to
`$MAKEFUN_OUTPUT_DIR/entry.txt`, reads it back, and verifies it
byte-for-byte (1–199 characters, UTF-8, not whitespace-only).
